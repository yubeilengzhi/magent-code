# 中文文档排版

中文 + 英文 + 数字混排时，需要注意排版细节。

## 中英文之间

✅ 推荐：在中文和英文之间加空格
```
使用 SQLite 数据库
使用 TypeScript 编写代码
```

❌ 避免：中文和英文之间没空格（密集感）
```
使用SQLite数据库
使用TypeScript编写代码
```

## 中文与数字

✅ 推荐：数字前后加空格
```
今天买了 3 个苹果
总共有 100 个用户
```

## 全角 / 半角

- 中文用全角标点：，。；：？！""''（）
- 英文用半角标点：, . ; : ? ! "" '' ()
- 不要混用

✅ 推荐：
```
你好，世界！这是一个例子（test）。
```

❌ 避免：
```
你好,世界! 这是一个例子(test)。
```

## 数字与单位

✅ 推荐：
```
5 GB、3.14、10%
```
（数字和单位之间加空格）

## 专有名词

保留英文（如 SQL、TypeScript、API），不要硬翻译：
- ✅ SQL 数据库（不是"结构化查询语言数据库"）
- ✅ API 接口（不是"应用程序编程接口接口"）
- ✅ TypeScript 类型系统（不是"类型脚本类型系统"）

## 链接

✅ 推荐：链接用 Markdown 语法，文字描述性
```markdown
更多信息请参考 [Claude Code 文档](https://docs.anthropic.com)
```

❌ 避免：链接直接显示 URL
```markdown
更多信息请参考 https://docs.anthropic.com
```

## 标题层级

- 一级标题：一篇文章只有一个
- 二级标题：主要章节
- 三级标题：小节
- 避免跳跃层级

## 代码引用

行内代码用反引号：
```
使用 \`magent run\` 命令启动任务
```

## 列表

有序列表用 `1.` （让 Markdown 自动编号）：
```
1. 第一步
2. 第二步
3. 第三步
```

无序列表用 `-`：
```
- 项目 1
- 项目 2
```

## 强调

- 重要内容用 **加粗**
- 不要用斜体（中文显示效果差）
- 引用他人用 > blockquote

## Anti-Pattern

- ❌ 中英文之间无空格（密集）
- ❌ 全角半角标点混用
- ❌ 硬翻译专有名词
- ❌ URL 直接展示
- ❌ 层级跳跃（从 # 直接到 ###）

## Checklist

- [ ] 中英文之间有空格
- [ ] 标点使用一致（全角中文/半角英文）
- [ ] 数字格式正确
- [ ] 专有名词保留英文
- [ ] 链接用 Markdown 语法
- [ ] 标题层级正确
